## Required packages

library(tidyverse)
library(dplyr)
library(Kendall)
library(ggplot2)
library(ggpubr)
library(rmarkdown)

## Reproducing the analysis

You will need to download the .rds files to reproduce the analysis in R. 
Data are also provided in .csv format.
To run the code, open `SIeves markdown.Rmd` in RStudio, and press **Knit**.
